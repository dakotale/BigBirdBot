Overview

🎵

Music Player

YouTube, Spotify, SoundCloud, and direct URLs. Full queue management, seek, loop, shuffle, volume, and interactive button controls.

🔑

Keywords

Map trigger words to images, GIFs, files, or text. Aliases, bulk attachments, and scheduled recurring DM deliveries.

Multi-turn conversations with 5 character personas or 13 mental-health / identity support guides, powered by Claude.

AutoRole

Automatically assign a role to every new member, with an optional one-click backfill for the whole server.

🔨

Moderation

Kick, ban, timeout, slowmode, and role management — every action permission-checked against both the caller and the bot.

🎂

Birthdays & Reminders

Automatic birthday shout-outs and personal DM reminders, both aware of your saved /timezone.

All commands are server-specific unless noted otherwise. Once an hour, the bot also posts a hint for a Bonus Word Puzzle in servers with announcements enabled — first member to guess the secret word gets a shout-out, no reward beyond bragging rights.

Music

Powered by Lavalink4NET. Supports YouTube, Spotify, SoundCloud, and direct URLs (Twitter/X links are resolved automatically). The now-playing embed includes interactive Pause/Resume, Skip, Stop, Shuffle, Loop, and Volume buttons. The bot automatically rejoins a voice channel and resumes its queue if the connection drops and reconnects.

/join
Join your current voice channel.
/leave
Leave the voice channel and clear the queue.
/play
Play a track or an entire playlist from a search query or URL. Joins your voice channel automatically if not connected.
query
/playnext
Same as /play but inserts the track immediately after the current one instead of at the end.
query
/pause
Pause the current track.
/resume
Resume the paused track.
/forceskip
Skip the current track immediately.
/stop
Stop playback, clear the queue, and disconnect.
/nowplaying
Show the currently playing track with playback buttons.
/queue
Show the upcoming tracks in the queue, paginated 10 per page.
/volume
Set playback volume 0–100. Persists per server.
0–100
/loop
Set the repeat mode: off, current track, or the whole queue.
mode
/shuffle
Randomise the current queue order.
/clear
Remove all tracks from the queue without stopping playback.
/remove
Remove a specific track from the queue by position.
position
/swap
Swap two tracks in the queue by position.
pos Apos B
/seek
Jump to a specific timestamp in the current track (e.g. 00:01:30).
timestamp

Keywords

Register a trigger word per server — when a member's message contains it, the bot replies with a randomly-picked entry (image, file, or link) registered under that keyword. Entries can have aliases, bulk file uploads, and users can subscribe to a recurring DM delivery. All grouped under /keyword to keep the command list small. Requires Manage Messages.

/keyword add
Register a new keyword and create its backing storage folder.
keyword
/keyword delete
Permanently remove a keyword and all its mappings.
keyword
/keyword rename
Rename an existing keyword and move its storage directory to match.
oldnew
/keyword info
Show entry count, creator, and up to 5 recent entries for a keyword.
keyword
/keyword list
List all keywords registered in this server, paginated.
/keyword alias add
Create a trigger word that serves entries from an existing keyword.
aliaskeyword
/keyword alias delete
Remove a keyword alias.
alias
/keyword alias list

keyword
/keyword attachment add
Attach up to 10 files to one or more comma-separated keywords at once.

/keyword url delete

urlkeyword
/keyword schedule add
Schedule a recurring DM delivery of a keyword for a user.
@userkeyword
/keyword schedule remove

/keyword schedule list

/keyword schedule requeue Owner

AutoRole

Automatically assigns a configured role to every new member who joins. Requires Manage Roles (bot and user).

/autorole set
Set the role to assign when a new member joins. Warns if the role sits above the bot's own role (assignment would fail).
rolebackfill?
/autorole clear
Remove the auto-role setting for this server.
/autorole status
Show the current auto-role configuration.

Moderation

Each command requires the matching Discord permission from both the invoking user and the bot, and refuses targets that neither the caller nor the bot outranks by role hierarchy.

Kick a member. Requires Kick Members.
memberreason?

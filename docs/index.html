Music

Supports YouTube, Spotify, SoundCloud, and direct URLs. The now-playing embed includes interactive pause / resume / skip buttons.

/clear
Remove all tracks from the queue without stopping playback.
/forceskip
Skip the current track immediately.
/join
Join your current voice channel.
/leave
Leave the voice channel and clear the queue.
/loop
Queue the current track N additional times.
times
/nowplaying
Show the currently playing track with a progress bar and playback controls.
/pause
Pause the current track.
/play
Play a track or playlist from a search query or URL. Joins automatically if not connected.
query
/playnext
Same as /play but inserts the track next in the queue instead of at the end.
query
/queue
Show upcoming tracks in the queue.
/remove
Remove a specific track from the queue by position.
position
/repeat
Queue the current track one more time.
/resume
Resume the paused track.
/seek
Jump to a specific timestamp in the current track (e.g. 00:01:30).
timestamp
/shuffle
Randomise the current queue order.
/stop
Stop playback, clear the queue, and disconnect.
/swap
Swap two tracks in the queue by position numbers.
pos Apos B
/volume
Set playback volume 0–100. Persists per server.
0–100

Playlists

Save and restore named queue snapshots, stored per user per server. Loading a playlist rejoins your voice channel and requeues every track via Lavalink. Saving overwrites any existing playlist with the same name.

/playlist delete
Permanently delete one of your saved playlists.
name
/playlist list
Show all your saved playlists with track counts. Visible only to you.
/playlist load
Restore a saved playlist into the current queue. Bot joins your voice channel automatically.
name
/playlist save
Snapshot the current queue and now-playing track as a named playlist. Overwrites if the name already exists.
name
